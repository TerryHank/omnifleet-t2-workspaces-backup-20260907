# MSC-V1 对齐表：v0.2.0

范围：104 / 113 两车，纵队、横队、一字型。用户明确不做实车运动，三角队形与三车降级排除。

下表的“软件通过”指状态输入、几何或隔离 ROS 回归，不表示实车动态验收通过。“静态通过”只覆盖现场静止时的真实链路。不能把本版称为完整实车协同闭环。

证据：`evidence/shared_map_dsh/software-acceptance-latest.json`（43 项）、`native-isolated-tests-latest.log`、两车 `shared-map-probe.json`、`planning.json`、`peer-layer.json`、`final-static-probe.json`，以及 `websocket-diagnostic.json`。历史 v0.1 对照保留在 TRACEABILITY.md。

## 必须留给后续的实体验收

三航点编队、实际转弯/窄道、静态和横穿障碍、运动中失联、真实急停制动距离、故障领车切换与跟车归队都没有实车运动证据。持续定位漂移也需要动态检查。软件通过不能替代这些验收。

104 没有安装热参数面板，当前没有专用车队控制面板。操作接口为 `msc` 命令和标准车队话题；DSH 不应要求用户点击不存在的面板。原始 104 MOLA 地图仍可用于定位检查，两个全局规划器实际使用 `/fleet/map`。
