# Robot 113 Foxglove layouts

Current and historical layout/style snapshots collected from 113.

- `foxglove-layout-waypoint-costmaps.json`: current waypoint/costmap layout snapshot.
- `foxglove-fleet.json`: fleet layout reference.
- `config_backups/`: Foxglove Studio layout backups from the 113 user profile.
- `foxglove-layouts/`: older layout snapshots retained for comparison.

The Chromium/GPU/Web caches, cookies, session databases and live locks were excluded.
